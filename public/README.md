# Summit Properties favicon pack

Based on the site header's gold geometric brand mark (#bd9a5c) on a dark evergreen background (#14231e).

## Install (Vite)

1. Copy `favicon.svg`, `favicon.ico`, all `.png` files, and `site.webmanifest` into the project's `public/` directory.
2. Paste the contents of `head-snippet.html` into the `<head>` of each HTML entry point:
   - `index.html`
   - `blog/questions-before-choosing-a-home/index.html`
   - `blog/evaluate-property-potential/index.html`
3. Run `npm run build`, commit and push.

The favicon is a simplified small-size adaptation of the CSS brand mark, not a pixel-exact screenshot.
